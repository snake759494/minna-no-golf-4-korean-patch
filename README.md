## 패치 적용 방법

해시가 일치하는 원본 일본판 v2.00 ISO에 첨부 xdelta를 적용하세요. xdeltaUI도 사용할 수 있습니다.

```text
xdelta3 -d -s "Minna no Golf 4 (Japan) (v2.00).iso" "Minna_no_Golf_4_PS2_KO_v0.9.0-beta.xdelta" "Minna no Golf 4 (Japan) (v2.00) (Korean).iso"
```

패치 적용 후 새 ISO로 부팅하세요. 이전 ISO에서 만든 세이브스테이트를 불러오면 수정 이전 데이터가 남을 수 있습니다.

## 검증과 알려진 한계

xdelta 복원 결과의 전체 SHA-256이 최종 ISO와 일치합니다. 정적 검사와 최종 ISO 부팅·메인 메뉴·코스 선택·경기 전 최종 확인 화면을 확인했습니다.
이름 입력·종료·성적표·플레이어 선택 수정은 원본 대조 및 이미지/바이너리 검사를 완료했지만 해당 화면의 최종 ISO 실행 재확인은 남아 있습니다.
전체 모드·전체 플레이·모든 3D 장식과 영상까지 일본어 잔존이 없음을 보장하지 않습니다. MTI 구조 교정은 수정 대상 84종이며 전체 2,195종 교정 완료가 아닙니다.

ISO는 배포하지 않으며 릴리즈 첨부는 xdelta 차분 하나입니다. 번역 자료에는 스포일러가 있습니다.
