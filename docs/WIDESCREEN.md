## PCSX2 16:9 와이드 패치 사용법

릴리즈 첨부 파일 `SCPS-15059_BC4C7335.pnach`를 한글패치 xdelta와 함께 제공합니다. 선택 사항이며 ISO를 다시 빌드할 필요는 없습니다.

### 대상 확인

- 모두의 골프 4 일본판 v2.00 및 이를 기반으로 만든 한글판.
- 게임 ID `SCPS-15059`, 실행 파일 CRC `BC4C7335`.
- PCSX2의 게임 속성이나 실행 로그에서 CRC를 확인하세요. 다른 CRC에는 파일명만 바꾸어 적용하지 마세요.

### 설치와 활성화

1. 한글패치 xdelta를 원본 ISO에 적용합니다. 이미 한글판을 사용 중이면 이 단계는 생략합니다.
2. 릴리즈에서 `SCPS-15059_BC4C7335.pnach`를 다운로드합니다. 확장자가 `.pnach.txt`가 되지 않도록 확인합니다.
3. PCSX2에서 **도구 → 데이터 디렉터리 열기**를 선택하고, 그 안의 **patches** 폴더에 파일을 복사합니다. 폴더가 없으면 만듭니다. 일반적인 Windows 경로는 `문서\PCSX2\patches`이며, 포터블 설치는 위치가 다를 수 있으므로 메뉴로 확인하세요.
4. 게임 목록에서 모두의 골프 4를 우클릭하여 **속성 → 패치**를 열고 **Widescreen 16:9**를 활성화합니다. 버전에 따라 **와이드스크린 패치 활성화** 옵션으로 표시될 수 있습니다. 치트 폴더에 넣거나 치트 활성화 옵션을 켤 필요는 없습니다.
5. 그래픽의 화면 비율은 **자동(4:3/3:2)**으로 둡니다. 패치가 16:9를 요청합니다. 구형 버전에서 자동 전환이 되지 않으면 패치를 켠 상태에서 화면 비율을 16:9로 지정하세요. 비율 설정만 바꾸는 것은 시야 확장 패치 적용과 다릅니다.
6. 게임을 완전히 종료하고 해당 ISO를 새로 부팅합니다. 처음 확인할 때는 이전 세이브스테이트를 불러오지 마세요. 메모리 카드의 게임 저장 데이터는 사용할 수 있습니다.

### 적용 확인 및 문제 해결

- 패치 목록에 `Widescreen 16:9`가 나타나고 활성화되어 있는지 확인합니다.
- 실행 로그에는 `Enabled patch: Widescreen 16:9`와 16:9 화면 비율 요청이 표시됩니다(로그 문구는 버전별로 다를 수 있음).
- 경기의 3D 화면에서 좌우 시야가 넓어집니다. 단순히 화면만 가로로 늘어나는 경우 CRC·폴더·확장자·활성화 상태를 다시 확인하세요.
- 패치가 목록에 없으면 PCSX2를 재시작하고, 현재 PCSX2의 데이터 폴더에 설치했는지 확인합니다.
- 같은 게임의 다른 와이드 코드와 동시에 사용하지 마세요. 기존 `BC53B2E5`용 코드를 현재 CRC로 이름만 바꾼 파일도 중복 사용하지 않습니다.
- 해제하려면 게임 속성에서 와이드 패치를 끄고 화면 비율을 자동으로 되돌린 다음 새로 부팅하세요.

### 검증 범위와 한계

PCSX2 v2.9.94에서 한글판의 패치 로드, 16:9 전환, 동일 경기 상태의 적용 전후 좌우 시야 확장, 경기 카메라 명령어와 투영값, 새 부팅의 메뉴 명령어 반영을 확인했습니다.
2D HUD·메뉴 그림·문자는 원본 배치를 사용하므로 가로로 늘어납니다. 전체 코스·모든 카메라·리플레이·동영상과 PS2 실기는 검증하지 않았습니다.
